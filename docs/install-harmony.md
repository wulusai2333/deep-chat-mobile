# 在鸿蒙 4.3 上安装

目标机型：华为 Mate 70 Pro+（HarmonyOS 4.3 / API 兼容层）。
APK 走的是鸿蒙内置的 Android 兼容层，不需要任何「刷机」「开发者模式」之类的操作。

> 本文以鸿蒙 4.3 为例。**其他 Android 7.0+ 机型（含鸿蒙 4.x）的兼容范围、WebView 要求、
> 平板/横屏限制**见 [README「支持的设备与系统」](../README.md#支持的设备与系统大致范围)；
> 非鸿蒙 Android 手机的安装流程基本相同，只是「未知来源/纯净模式」的入口名称不同。

---

## 0. 先确认三件事

1. **系统版本是 4.x 而不是 NEXT**
   设置 → 关于手机 → 查看「HarmonyOS 版本」。
   如果是 **HarmonyOS NEXT（5.0 及以上）**，系统已彻底移除 Android 兼容层，**APK 装不上**。
   这种情况请用 PWA 方案，见 [build.md §8](./build.md#8-pwa-兜底)。

2. **手机有足够空间**：APK 约 5.4 MB，加一份解压后的数据约 20 MB。

3. **准备好 API Key**：首次启动要输入。没有 Key 进不去主界面。

---

## 1. 允许安装未知来源应用

鸿蒙 4.3 默认禁止侧载。要放行的是**你用来打开 APK 的那个应用**（文件管理器 / 浏览器 / 微信），
不是「所有应用」。

### 路径

```
设置 → 安全 → 更多安全设置 → 安装外部来源应用
```

在列表里找到你打算用来点开 APK 的应用（通常是「文件管理」），把开关打开。

> 不同机型/版本的菜单名略有差异，也可能是：
> `设置 → 应用和服务 → 应用管理 → 特殊访问权限 → 安装未知应用`
> 或者 `设置 → 隐私 → 更多隐私设置 → 安装未知应用`
>
> 找不到的话，直接在设置顶部搜索框搜「安装未知」或「外部来源」。

**用 adb 装则不需要这一步** —— 见 [§5](#5-用-adb-安装开发时用)。

---

## 2. 把 APK 传到手机

任选一种：

| 方式 | 步骤 |
| --- | --- |
| USB | 数据线连电脑 → 选「文件传输」→ 把 APK 拖进手机 `Download/` |
| 微信 | 电脑微信「文件传输助手」发给手机 → 手机上点开 → 右上角「用其他应用打开」→ 文件管理 |
| 网盘 | 上传后手机端下载到本地 |

> 提醒：从微信直接点 APK 有时会被当成聊天文件预览。建议先「保存到手机」再从文件管理打开。

---

## 3. 安装

在文件管理里找到 APK，点击。

### 3.1 会遇到的两个拦截

**（a）纯净模式拦截**

提示「该应用未经华为安全检测」或「为保护您的权益，已阻止安装」。这是鸿蒙的纯净模式。

处理：
1. 点**「继续安装」**（不是「取消」）
2. 可能需要**登录华为账号**并同意条款
3. 若没有「继续安装」按钮，先去关掉纯净模式：
   `设置 → 系统和更新 → 纯净模式 → 退出纯净模式`
   装完可以再打开

**（b）「应用来源未知」**

如果你是从浏览器下载的，会提示来源风险。点「仍然安装」即可。

### 3.2 安装过程中可能出现的提示

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | APK 文件损坏，或系统版本低于 Android 7.0（API 24） | 重新传一次；确认系统是 4.x |
| 「应用未安装」 | 已装过签名不同的版本 | 先卸载旧版（**会清数据**），再装 |
| 「与已有应用冲突」 | 包名 `com.deepchat.app` 已被占用 | 同上 |

---

## 4. 首次启动

### 4.1 首启引导

打开应用，会看到三步引导：

1. **说明**：数据只存在本机，Key 加密保存
2. **输入 Key**：粘贴你的 `sk-...`
3. **校验**：点「验证并继续」，应用会请求 `GET /models` 确认 Key 可用

验证通过才进主界面。Key 存在 Android Keystore 保护下的加密存储里（详见
[../native/secure-storage/README.md](../native/secure-storage/README.md)）。

> **Key 输错了会怎样**：提示「API Key 无效」，停在当前页可以重输。
> 若验证接口本身失败（断网 / Key 无 `/models` 权限），也会给出可读的提示，而不是卡住。

### 4.2 跳过引导

引导右下角有「稍后设置」。跳过会落到上游的设置面板。
但**没有 Key 无法发消息** —— 这个顺序是刻意的：不让用户在不知情的情况下进入一个「什么都不能做」的界面。

### 4.3 之后每次启动

**不会再要求输入 Key**。启动时从加密存储读出、只放进内存。

如果某次启动又出现了引导，说明设备上的加密存储被清了（卸载重装、清应用数据、或用另一个签名覆盖安装）。

## 5. 用 adb 安装（开发时用）

比传文件快，也不需要放行未知来源。需要一台电脑 + USB 调试。

### 5.1 开启开发者模式

```
设置 → 关于手机 → 连续点击「版本号」7 次 → 提示「已进入开发者模式」
设置 → 系统和更新 → 开发人员选项 → 打开「USB 调试」
```

### 5.2 连接并安装

```powershell
$env:ANDROID_HOME = 'D:\soft\android-sdk'
$adb = "$env:ANDROID_HOME\platform-tools\adb.exe"

& $adb devices          # 手机上会弹「允许 USB 调试吗」，勾选「始终允许」
& $adb install -r "dist-apk\deep-chat-0.2.4-x64-release.apk"
```

装完可以直接看日志，排查问题非常有用：

```powershell
& $adb logcat -s Capacitor/Console:V Capacitor:V chromium:V
```

### 5.3 卸载

```powershell
& $adb uninstall com.deepchat.app
```

**注意会清掉全部会话数据。** 卸载前先在应用内「设置 → 数据 → 导出」备份。

## 6. 权限

应用只申请三个权限，安装时不会问你要任何东西：

| 权限 | 级别 | 用途 |
| --- | --- | --- |
| `INTERNET` | 普通 | 访问 `api.deepseek.com` |
| `RECORD_AUDIO` | **危险** | 语音输入。**首次点录音时**才弹授权框 |
| `MODIFY_AUDIO_SETTINGS` | 普通 | WebView 录音链路必需（见 [build.md §11](./build.md#11-一个容易忽略的坑录音权限)） |

**没有**存储权限。导入 ZIP 走系统文件选择器（SAF），保存备份走 MediaStore —— 都不需要存储权限。

### 6.1 麦克风被拒绝后怎么恢复

- 首次拒绝后，下次点录音**系统会再弹一次**
- 若连续拒绝两次（或选择「不再询问」），系统不再弹框。此时应用会显示引导浮层：
  点「去设置」直达 `设置 → 应用 → Deep Chat → 权限`

手动路径：

```
设置 → 应用和服务 → 应用管理 → 找到 Deep Chat → 权限 → 麦克风 → 允许
```

### 6.2 为什么系统设置里麦克风显示「已允许」，语音输入还是失败

这种情况通常不是权限问题，先按顺序排查：

1. **Key 没有 ASR 权限** —— `/v1/tools/asr` 返回 401/404。换个有权限的 Key。
2. **没有声音设备** —— 蓝牙耳机已断开但系统仍认为在用蓝牙麦克风。断开重连。
3. **其他应用占用麦克风** —— 通话、录音机在后台运行。关掉它们。
4. **静音/勿扰模式下录音仍可用**，但**朗读会没声音** —— 检查媒体音量。

## 7. 导入桌面端的会话历史

### 7.1 桌面端导出

在电脑浏览器里打开 chat-demo，`设置 → 数据 → 导出`，得到 `deepseek_data-<日期>.zip`。

### 7.2 传到手机

微信 / USB / 网盘均可，记住存在哪。

### 7.3 两种导入方式

**方式 A：应用内**

```
应用 → 设置 → 数据 → 导入 → 选择文件
```

系统会弹出文件选择器（这是系统的，不是应用自绘的），选那个 ZIP。

**方式 B：从文件管理器直接打开**

在文件管理里点 ZIP → 「用其他应用打开」→ 选 Deep Chat。
应用会被拉起并直接开始导入。

> 方式 B 依赖 manifest 里的 intent-filter。若列表里没有 Deep Chat，
> 说明系统文件管理器没把它识别为 ZIP 处理者，用方式 A。

### 7.4 导入会发生什么

1. **先自动备份**当前全部会话到 `Documents/DeepChat/deep-chat-backup-<时间>.zip`
   —— 备份失败会中止导入，不会在没有退路的情况下动数据
2. **合并**（不是覆盖）：同 id 的会话取 `updatedAt` 更新的那份；id 不同的追加
3. 结果页显示：**新增 / 更新 / 跳过 / 失败** 四个数字 + 备份路径

### 7.5 备份与导出文件在哪

应用会往同一个目录写两类 ZIP：

| 来源 | 文件名 | 什么时候产生 |
| --- | --- | --- |
| 应用内导出 | `deep-chat-export-<日期>-<时间>.zip` | `设置 → 数据管理 → 下载`，手动导出全部会话 |
| 导入前自动备份 | `deep-chat-backup-<日期>-<时间>.zip` | 每次合并导入前自动生成 |

```
文件管理 → 文档 → DeepChat → 上面两类 ZIP
```

- **Android 10（API 29）及以上**：通过 MediaStore 写入，路径显示为 `Documents/DeepChat/`
- **Android 7.0–9（API 24–28）**：写入应用专属外部目录
  `Android/data/com.deepchat.app/files/Documents/DeepChat/`
  这个目录在文件管理器里可能看不见，需要用 adb 或第三方文件管理器访问。
  （鸿蒙 4.3 对应 API 31，走的是前者。）
- 应用内导出的浮层会直接显示完整落盘路径；失败时会说明原因，可以原地重试。
  > 0.2.3 及以前，应用内「导出」在 Android 上**不会写文件**（WebView 不支持
  > `<a download>`，也没有 DownloadListener），升级到 0.2.4 后才真正落盘。

### 7.6 重复导入同一个 ZIP

安全。连导三次，会话数不变 ——

1. 账本（localStorage，只存 id 与消息计数，无敏感内容）命中直接跳过
2. 即使账本被清，`updatedAt` 不比本机新的也会跳过

## 8. 已知限制

诚实地列出来，而不是让用户自己撞：

| 限制 | 说明 |
| --- | --- |
| **鸿蒙 NEXT 无法使用** | 系统级移除 Android 兼容层。升级后只能用 PWA（功能有降级，见 build.md §8.4） |
| **后台被清理** | 长时间切到后台，系统可能杀掉进程。正在进行的回复会中断（已收到的部分保留） |
| **部分 Key 功能不可用** | 联网搜索 / 网页读取 / 语音识别取决于 Key 权限，401/404 时应用会提示而非崩溃 |
| **朗读需要音量** | 静音或媒体音量为 0 时「朗读」没声音，这是系统行为 |
| **不支持分屏** | 应用是 `singleTask` + 竖屏优先，分屏下布局可能挤压 |
| **无多设备同步** | 设计如此：数据只在本机，跨设备靠手动导入 ZIP |

## 9. 数据在哪、怎么彻底清除

| 数据 | 位置 | 清除方式 |
| --- | --- | --- |
| 会话 / 附件 | 应用私有 IndexedDB | 应用内「设置 → 数据管理 → 删除」，或卸载 |
| API Key | EncryptedSharedPreferences（密钥在 Android Keystore） | 应用内设置里清除，或卸载 |
| 导出 / 导入备份 ZIP | `Documents/DeepChat/` | 在文件管理里手动删 |

**卸载会清掉前两项，但不会删 `Documents/DeepChat/` 里的 ZIP** —— 那是刻意设计，
防止误卸载后连退路都没了。要彻底清除请手动删那个目录。

`allowBackup="false"`，所以这些数据**不会**被系统云备份带走 —— 换手机不会自动迁移，
需要手动导出 ZIP 再导入。

## 10. 出问题怎么反馈

收集这三样：

1. **系统版本**：设置 → 关于手机 → HarmonyOS 版本
2. **应用版本**：应用内 设置 → 关于（或看 APK 文件名 `deep-chat-0.2.4-...`）
3. **日志**（如果能连电脑）：

   ```powershell
   & $adb logcat -s Capacitor/Console:V Capacitor:V chromium:V > log.txt
   ```

   在应用里重现问题，然后 `Ctrl+C` 停止，把 `log.txt` 发出来。

白屏类问题优先看日志里有没有：
- `SyntaxError` / `Unexpected token` → WebView 内核太旧，见 [build.md §7](./build.md#7-老-webview-内核与降级)
- `net::ERR_CLEARTEXT_NOT_PERMITTED` → 明文流量被拦（不该发生，请报告）
- `NotAllowedError` → 麦克风权限链路
